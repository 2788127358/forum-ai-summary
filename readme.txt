为子比论坛帖子自动生成 AI 摘要与相关标签，并把 SEO 一次做完。

== Description ==

为子比（Zibll）主题内置论坛的帖子自动生成 AI 摘要与相关标签，并把 SEO 一次做完：写入子比「独立SEO」三要素、为标签与板块补搜索描述、正文语义内链、文末相关推荐。

* 发帖自动生成，失败自动重试；帖子标题改动后自动重整理 SEO。
* 标签只复用站内已有 `forum_tag`，不新建，避免产生大量低质归档页。
* 支持 OpenAI、DeepSeek、Anthropic 与任意兼容 OpenAI 协议的接口。
* 只作用于论坛帖子，不影响普通文章与页面。

== Installation ==

1. 上传插件目录到 `wp-content/plugins/`，或在后台「安装插件 → 上传插件」选择 zip。
2. 启用「论坛 AI 摘要」。
3. 进入「论坛AI摘要 → 设置」，选择模型供应商并填写密钥、接口地址与模型。

== Frequently Asked Questions ==

= 需要安装 bbPress 吗？ =

不需要。插件直接对接子比主题自带的论坛系统（`forum_post`）。

= 会改动帖子原标题吗？ =

不会。AI SEO 结果写入子比「独立SEO」字段，`post_title` 保持原样。

= 会不会产生大量新标签？ =

不会。AI 给出的标签只与站内已有 `forum_tag` 匹配，命中才写入关联，未命中即丢弃。

= 生成的摘要在哪里？ =

post meta `_fas_summary`；可选同时写入 `post_excerpt`。

== Changelog ==

= 2.2.1 =
* 修复：改标题后 AI SEO 不重整理。根因有三——① 存量帖的 SEO 由旧版本生成，没有 `_fas_seo_source_title` 基线；② 重整理只挂在 `post_updated`，主题 / 编辑器绕过 `wp_update_post` 直接写库时整条链路不启动；③ 低流量时段延迟事件可能丢失。
* 补了三层：保存时放宽旧数据判断（有 `_fas_seo_title` 即视为插件生成过）；「惰性兜底」——帖子保存后 1 小时内被访问时再比对一次标题基线，不一致即补排事件（同帖 10 分钟去抖）；「每小时巡检」——按修改时间倒序检查最近 7 天动过的帖子（单轮最多 30 篇），只对不一致的排事件，扫描本身不调模型。
* 巡检改为一次预取帖子与 meta，整轮固定 3 条查询，单次内存占用百 KB 量级。
* 结果：改标题并保存后 10 秒生效；绕过保存钩子或事件丢失的，最迟下一轮巡检自动收敛；升级前已漂移的存量帖也会在 7 天窗口内被巡检逐个修好。
